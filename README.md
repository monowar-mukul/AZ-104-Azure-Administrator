## Using the Repository

1. Open a lab page under `labs/`.
2. Review the services and intended outcome.
3. Follow the architecture flow sequence.
4. Replace the dummy hands-on URL with your own practical reference.
5. Add the corresponding diagram as `images/lab-xx/architecture.png`.

## Important

- Do not commit credentials, subscription IDs, access keys, secrets, private endpoints, or personal data.
- Resource names shown in diagrams should be labelled as examples.
- Microsoft product names and Azure role names should retain their official spelling.
